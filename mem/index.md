# Project Memory

## Core
App: "Auto Limpeza Pro". PWA Dark Theme (#090F15).
Foco: Higienização profissional (estofados, automotiva, pós-obra) em São José da Lapa e Vespasiano.
Tech: React 18 + Vite + Tailwind + react-router-dom + react-helmet-async.
Backend: Lovable Cloud (Real database: blog_posts, appointments, leads, neighborhoods).
Auth: Supabase Auth + user_roles (admin).
IA: Gerador de artigos SEO e Chatbot via Edge Functions.
